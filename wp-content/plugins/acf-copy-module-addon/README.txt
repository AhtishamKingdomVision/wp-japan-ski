A powerful addon for Advanced Custom Fields (ACF) that lets you save, copy, export, import, and reuse individual Flexible Content layouts as reusable modules. Ideal for developers building complex page templates with repeatable designs.

== Description ==

**ACF Copy Module Addon** extends Advanced Custom Fields (ACF) by adding the missing feature developers always wanted:

> 💡 **Save any Flexible Content layout as a reusable Module and insert it anywhere with one click.**

Perfect for:
- Page builders built with ACF
- Modular website design
- High-speed landing page creation
- Reusing complex layouts across multiple pages
- Importing/exporting ACF section presets between websites

### 🔥 Core Features

#### ✅ Save ACF Flexible Content layouts as Modules
Right from the page editor, you can save any layout block as a named module.

#### ✅ One-click Insert Module button
Insert saved modules into any Flexible Content field.

#### ✅ Import & Export Modules (JSON)
Move modules between websites with a clean JSON import/export system.

#### ✅ Restore images, links, colors, repeaters & WYSIWYG fields
Full support for:
- ACF Image fields
- Link fields
- Color Picker fields
- Repeater fields inside layouts
- WYSIWYG editors
- Radio, Checkbox, Select, Number, Text fields

#### ✅ Works with any ACF Flexible Content structure
No theme dependency. Works with:
- Elementor + ACF
- Gutenberg + ACF
- Custom themes
- Oxygen, Bricks, GeneratePress, Block Themes
- Headless setups

#### ⚠ ACF Dependency Notice
This addon depends heavily on internal ACF JavaScript APIs.  
Whenever **Advanced Custom Fields** releases major updates, this addon **may require an update**.

We actively maintain compatibility.

== Installation ==

1. Install and activate **Advanced Custom Fields Pro**.
2. Upload and activate **ACF Copy Module Addon**.
3. Go to any page that uses ACF Flexible Content.
4. You will see:
   - **Save Module** button on each layout
   - **Insert Module** button at the top
5. Enjoy super-fast modular page building.

== Frequently Asked Questions ==

= Does this require ACF Pro? =
Yes. Flexible Content is only available in ACF Pro.

= Are nested repeaters supported? =
Yes — including images, links, colors, and all core ACF field types.

= Will modules break after updating ACF? =
This addon depends on ACF’s internal JavaScript API.  
If ACF changes their internal framework, an update may be required.  
We maintain compatibility for WordPress 5.5+ and ACF 6+.

= Does this work with custom Gutenberg ACF blocks? =
Yes, as long as the block uses Flexible Content inside it.

= Can I move modules between staging and production? =
Yes — use the JSON Import/Export feature.
